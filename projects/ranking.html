랭킹 수집

쇼핑몰 순위로 시장의 움직임을 읽습니다 · 2026년 4월 시작

제가 쇼핑몰을 돌며 순위와 리뷰를 손으로 확인하던 일을 덜어 줍니다.

PLAN기획무엇을 풀려 했나 BUILD개발무엇을 만들었나 APPLY적용일에 어떻게 붙였나 RESULT결과무엇이 달라졌나
01 PLAN

기획

예전에는 쇼핑몰에 직접 들어가 순위를 보고 리뷰를 읽으며 손으로 정리했습니다. 그러다 보니 볼 수 있는 리뷰가 적었습니다. 주요 쇼핑몰에서 어떤 상품이 팔리는지, 객단가는 얼마인지, 리뷰는 어떤지를 체계적으로 갖춰 두고 싶었습니다. 4월에 처음으로 직접 만든 도구입니다.

  • 순위는 매주, 검색어는 매일 자동으로 모으기
  • 잘 팔리는 상품의 리뷰는 한 달에 한 번 AI와 함께 읽기
02 BUILD

개발

  1. 4월 초첫날에 수집, 엑셀 정리, 카드 이미지 만들기를 명령 한 줄로 이어 붙였습니다.
  2. 4월 말카드뉴스 첫 장이 나왔습니다.
  3. 5월월간 분석을 자동으로 도는 부분과 사람이 손대는 부분으로 다시 나눴습니다.
  4. 11월격주로 열리는 상품 아이디어 회의에 가져갈 주간 요약을 붙였습니다.
돌아가는 순서
쇼핑몰 5곳 순위와 검색어
검색어는 매일, 순위는 매주 모으기
순위 변화 정리, 카드 만들기
제가 월간 분석을 시작
잘 팔리는 상품의 리뷰 분석
누가 무엇을 하나
  • 자동쇼핑몰 순위와 검색어를 모으고 카드를 만듭니다.
  • AI한 달에 한 번, 잘 팔리는 상품 리뷰에서 사는 이유와 망설이는 이유를 골라냅니다.
  • 사람월간 분석은 제가 직접 시작하고, 거기서 무엇을 기획할지도 제가 정합니다.
03 APPLY

적용

정해진 시각

검색어는 매일 12시 30분, 순위 카드는 일요일 9시에 만들어지고, 리뷰 분석은 한 달에 한 번 합니다.

가장 자주 손본 곳

가장 자주 고친 건 쇼핑몰 쪽 변화였습니다. 쇼핑몰 화면이 바뀔 때마다 맞춰 고쳤고, 그 일이 4월부터 10월까지 이어졌습니다.
